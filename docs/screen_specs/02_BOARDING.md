# Screen 02 — Boarding

## Goal
입장 행위 자체를 기억에 남게 만든다.

## Sequence
1. Name / role
2. `BOARDING...`
3. plane route motion
4. `탑승 완료`
5. 가족 탑승 현황

## Copy
`류정원`
`전가네 큰손자`

`후쿠오카행 전가네 가족여행에 합류했습니다.`

## Status
`7 / 9 탑승 완료`

Boarded:
- full avatar/card
- check

Online(optional):
- green dot

Not boarded:
- muted placeholder

Current member:
- `방금 탑승`

## CTA
`여행 시작하기`

## Motion
600~1200ms 내 종료.
reduced motion에서는 progress fade로 대체.
